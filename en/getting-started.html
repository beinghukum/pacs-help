Getting started

PACS Auto types your Excel data into the PACS Computerised ERP website for you. You fill a sheet in Excel, press one button, and PACS Auto does the same clicks a person would do on PACS - row by row - and writes the result back into your sheet.

1Install→2Log in→3Login to PACS→4Open a module→5Test→6Make

1. What you need

  • A Windows PC with Microsoft Excel and Google Chrome, and internet.
  • Your PACS Auto username and password (from your seller) - or start a free trial (part 3).
  • Your society's PACS website User ID and password (the same ones you use on PACS every day).

2. Install

  1. Run the setup file PACS_Auto_Setup_<version>.exe you got from your seller. No administrator password is needed.
  2. The setup puts a PACS Auto icon on the Desktop and in the Start menu.
  3. Your working file is Documents\PACS Auto\PACS_Auto.xlsm. Always open PACS Auto from the icon - not by copying this file somewhere else.
Install once. New versions come by themselves - see part 8 (read it: after an update the sheets are empty).

3. Log in to PACS Auto

Double-click the PACS Auto icon. The login window opens.

Test ...Ribbon · Run (selected row)
↑ picture

Fills the PACS page for the selected row in Chrome but does not save it - to check everything first.

When to use

  • First time on a new day, or after you change a choice at the top of the sheet.
  • A row that gave an ERROR - to see what PACS says.

What happens

  1. A "please check" window - Enter = Start.
  2. Chrome fills the page.
  3. STATUS = TESTED. Nothing is saved on PACS.
Make ...Ribbon · Run (selected row)
↑ picture

Saves the selected row only on PACS. Before it, a "please check" window shows what will be done - read it and click the green button. Enter does not start a saving run.

When to use

  • One member at the counter.
  • A row again after you fixed its ERROR.

What happens

  • STATUS = DONE + PACS's numbers in the grey columns.
  • Khad Sale: a row that is already DONE is warned in red first.
Make Bulk ...Ribbon · Run (selected row)
↑ picture

Saves every row from the selected row down to the first empty row, one by one. Rows already DONE (and CHECK / SAVING rows) are skipped. Asks first in the "please check" window.

When to use

  • The normal daily work - click the FIRST row you want, then press it.

What happens

  • Rows turn DONE one by one.
  • A refused row = ERROR, the run goes on with the next row.
Pause / ResumeRibbon · Run (selected row)
↑ picture

Waits after the current row. The button then says Resume - press it to go on. While paused, PACS is kept logged in.

StopRibbon · Run (selected row)
↑ picture

The current row finishes - a Save on PACS is never cut in the middle - then the run stops. Next time select the first row that is not DONE and run again.

Clear SheetRibbon · Run (selected row) · on every data sheet
↑ picture

Deletes all rows of this sheet - to start a new day. It asks first (No is the default) and saves a copy of the file in Desktop \ PACS Auto Files \ Backups before.

Stays

  • The headings, your khad columns, the website lists and the choices at the top.
  • All other sheets.

Good to know

  • Not possible while a run is going on.
  • Ctrl+Z cannot bring the rows back - use the copy.
  • Look at SAVING / CHECK rows on PACS first.

6. STATUS - what each word means

STATUSMeaningWhat to do
DONESaved on PACS.Nothing. The next run skips this row - it is never made twice.
ERRORNot saved. MESSAGE says why.Fix the reason; the next run tries the row again.
TESTEDTest only - nothing saved.Run Make when ready.
SAVING / CHECKSave was pressed, but the result was not clear (e.g. PACS logged out at that moment).Look on PACS. Saved: type DONE in STATUS. Not saved: clear STATUS and run again. These rows are skipped until you decide - so nothing is made twice.

To enter a row again, clear its STATUS.

7. Where your files are

  • Your data: Documents\PACS Auto\PACS_Auto.xlsm. The app saves it during every run.
  • On your Desktop, folder PACS Auto Files: Backups (copies made before an update and before Clear Sheet), Permits (Khad Sale PDFs) and a folder for the voucher PDFs of Share Deposit, Loan Collection, Cash Payment, Cash Receipt and Other Transfer.

8. Updates

  • When a new version is ready, the login window shows Update now; in Excel press Check for update (PACS Auto also looks by itself).
  • Excel asks first and tells you what will happen. Say Yes: Excel closes, the update installs and the login window opens again by itself (about a minute). Log in and press Open PACS Auto.
  • Do not click the PACS Auto icon again while it updates.
After an update every sheet is EMPTY. Your rows (permits, members, vouchers...) are saved first in a copy of the file in Desktop \ PACS Auto Files \ Backups. Kept as they are: the lists from PACS (godowns, categories, khad, ledgers, PDS items with your rates, loans), your khad and PDS item columns and your choices at the top of the sheets. Rows that are CHECK / SAVING are named in the question - look at them on PACS before you update.

9. Good to know

  • PACS Auto only prepares vouchers. Posting a voucher is always done by you on PACS.
  • Keep Admission No with its leading zeros (0000101, not 101).
  • Do not edit a cell in Excel while a run goes on - Excel then cannot write the results. Press Enter or Esc to leave the cell.
  • The PACS website calls a permit a Bill. In PACS Auto it is always a Permit.
  • A question this guide does not answer: Chat with support.
