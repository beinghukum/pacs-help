Khad Sale

Makes khad (fertilizer) permits on PACS for many members - one row = one permit. You type the member and the quantities in Excel; PACS Auto fills the PACS Sales page, saves it and writes the Permit No back into your row.

1. What this module does

It works on the PACS page Merchandise → Sales. For every row it opens the Sales page in your Godown, types the member's Admission No, adds each khad with its quantity, chooses the payment (Cash, or Credit on the member's loan account) and saves the permit. Then it writes DONE, the Permit No, the amount and the khad on the permit into your row.

The PACS website calls a permit a Bill. In PACS Auto it is always called Permit.

2. Before you start

  • You are logged in to PACS Auto and to PACS - green Logged in (see Getting started).
  • First time on this sheet: press Get Khad Details. It reads your godowns, categories and khad names from PACS (read only). Press it again when PACS gets a new khad.

Test PermitRibbon · Run (selected row)
↑ picture

Fills the permit of the selected row on the PACS website in Chrome, but does not save it. Use it to check everything once before you make real permits.

When to use

  • First time on a new day, or after you change Godown / Payment / Loan.
  • A member whose row gave an ERROR - to see what PACS says.

What happens

  1. The "please check" window opens - Enter = Start.
  2. Chrome fills member, khad, quantities and payment.
  3. STATUS = TESTED. Nothing is saved on PACS.

Make Bulk PermitRibbon · Run (selected row)
↑ picture

Makes permits for every row from the selected row down to the first empty row. DONE rows are skipped. It checks the PACS stock first and asks in the "please check" window.

When to use

  • Many members in one go - the normal daily work.
  • Click the FIRST row you want, then press it.

What happens

  1. Stock is compared with what the rows need.
  2. "Please check" window: rows, permits, login date.
  3. Rows turn DONE one by one; a refused row = ERROR and the run goes on.
Stock short? Permits are made only for the rows before the first row that has no stock. The rows after it wait, and their MESSAGE says why.

  • Ctrl+Z cannot bring the rows back - use the backup copy.
  • Look at SAVING / CHECK rows on PACS before you clear.

5. The columns

ColumnWhat goes in
SRYour own serial number (not sent to PACS).
Admission No *The member's Admission No exactly as on PACS - keep the leading zeros (0000101).
Khad columns (DAP, Urea...)The quantity of each khad. Leave it empty if the member does not take that khad. The columns come from PACS (Category).
Member NameLeave it empty - the app fills it from PACS. If you type it, it must match the name on PACS, otherwise no permit is made (a safety check for a wrong Admission No).
RemarkYour own note (not sent to PACS).
Village, Permit No, Permit Amount, Items in PermitFilled by the app after the permit is saved.

6. Step by step

1Type rows→2Match stock→3Test Permit→4Make Bulk Permit→5please check → Start→6DONE→7Sale Voucher
  1. Choose the settings at the top - Godown, Category, Payment, Account, Loan.
  2. Type the rows. One member per row: Admission No and the quantities. Pasting from your own register: check that each number lands under the right khad.
  3. Check the stock - Match khad stock with PACS.
  4. Test first - click a row, Test Permit.
  5. Make the permits - click the first row, Make Bulk Permit, read the "please check" window, click the green button.
  6. Watch each row turn DONE. Need a break? Pause / Stop.
  7. Next: the vouchers of these permits in Sale Voucher.

7. STATUS and common messages

STATUSMeaningWhat to do
DONEPermit saved on PACS.Nothing. The next run skips this row.
ERRORNot saved. MESSAGE says why.Fix the reason; the next run tries the row again.
TESTEDTest only - nothing saved.Run Make Permit when ready.
SAVING / CHECKSave was pressed but the result was not clear (e.g. PACS logged out at that moment).Look for this member's permit on PACS. Made: type DONE in STATUS. Not made: clear STATUS and run again.
MESSAGEWhat to do
This member has no Loans accountOn PACS the member has no account of the chosen loan. Open the loan account on PACS, or sell on Cash.
The website did not send this member's Loans account listPACS was slow. Run the row again.
... 2 KCC Kharif accounts, the first one was used (Loan No ...)Only information - the permit is DONE on the first account.
Credit Amount Cannot be Greater Than Loan Eligible AmountPACS refused: the member's loan limit is less than the permit. Reduce the quantity or check his limit on PACS. Nothing was saved.
Quantity in a hidden khad columnTick that khad in Khad Columns, or clear the quantity.
PACS logged outPress the button again - the app logs in again (captcha).

8. Good to know

  • Your Excel file is saved during the run, so a DONE permit is never lost and never made twice.
  • Before every Save the app checks that PACS is still logged in to your society.
  • If PACS refuses a Save, the row is ERROR and a Bulk run goes on with the next member.
