PACS Auto मदद

PACS Auto के हर मॉड्यूल की आसान गाइड। मॉड्यूल चुनें, या ऊपर खोजें। ऐप में यही गाइड रिबन से खुलती है: Help → "<sheet> guide"।

आप Excel में लिखते हैंएक row = एक परमिट, वाउचर या सदस्य
PACS Auto, PACS पर काम करता हैChrome में वही क्लिक जो एक व्यक्ति करता है
नतीजा वापस आता हैआपकी row में STATUS DONE / ERROR + PACS के नंबर

5 कदम में शुरू करें

1इंस्टॉलsetup एक बार चलाएँ - Desktop पर आइकन2लॉगिनPACS Auto लॉगिन, फिर Login to PACS (captcha)3मॉड्यूल खोलेंरिबन पर Modules ▾4TestPACS पर एक row भरता है - कुछ सेव नहीं5Makerows सेव करता है - STATUS DONE
